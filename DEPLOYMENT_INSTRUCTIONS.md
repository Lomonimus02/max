## 🔧 Пошаговое развертывание на Render

### Этап 1: Подготовка аккаунта Render (5 минут)

#### Шаг 1.1: Создание аккаунта
1. Перейдите на https://render.com
2. Нажмите кнопку "Sign Up" в правом верхнем углу
3. Выберите способ регистрации:
   - **GitHub** (рекомендуется) - самый быстрый способ
   - Google
   - Email
4. Если выбрали GitHub:
   - Авторизуйтесь в GitHub
   - Разрешите Render доступ к вашим репозиториям
5. Подтвердите email (если регистрация через Email)

#### Шаг 1.2: Подключение GitHub
1. В Render Dashboard перейдите в "Account Settings"
2. Найдите раздел "Connected Services"
3. Нажмите "Connect GitHub"
4. Авторизуйтесь и разрешите доступ

### Этап 2: Создание Web Service (10 минут)

#### Шаг 2.1: Создание нового сервиса
1. В Render Dashboard нажмите кнопку "New +"
2. Выберите "Web Service"
3. Нажмите "Connect a repository"

#### Шаг 2.2: Выбор репозитория
1. Найдите репозиторий `Lomonimus02/max`
2. Нажмите "Connect"
3. Выберите ветку: `consulting-website-render`

#### Шаг 2.3: Конфигурация сервиса

**Заполните следующие поля:**

| Параметр | Значение |
|----------|----------|
| **Name** | consulting-website |
| **Environment** | Node |
| **Build Command** | `npm run build` |
| **Start Command** | `npm start` |
| **Instance Type** | Free (или Starter для лучшей производительности) |

**Переменные окружения:**
- NODE_ENV = production

#### Шаг 2.4: Развертывание
1. Нажмите кнопку "Create Web Service"
2. Render начнет автоматическое развертывание
3. Дождитесь завершения (обычно 2-5 минут)
4. Вы получите URL вида: `https://consulting-website.onrender.com`

### Этап 3: Проверка развертывания (5 минут)

#### Шаг 3.1: Проверка статуса
1. В Render Dashboard найдите ваш сервис
2. Проверьте статус - должен быть "Live"
3. Нажмите на URL сервиса

#### Шаг 3.2: Тестирование сайта
Проверьте следующее:
- [ ] Сайт загружается без ошибок
- [ ] Все изображения отображаются корректно
- [ ] Навигация работает правильно
- [ ] Форма контактов функционирует
- [ ] Сайт адаптивен на мобильных устройствах
- [ ] Все ссылки работают

#### Шаг 3.3: Проверка логов
1. В Render Dashboard перейдите в "Logs"
2. Проверьте, нет ли ошибок
3. Убедитесь, что сервис работает корректно

### Этап 4: Настройка пользовательского домена (опционально, 15 минут)

#### Шаг 4.1: Добавление домена в Render
1. В Render Dashboard перейдите в "Settings"
2. Найдите раздел "Custom Domain"
3. Нажмите "Add Custom Domain"
4. Введите ваш домен (например: consulting.ae)

#### Шаг 4.2: Настройка DNS
1. Перейдите к вашему регистратору домена (GoDaddy, Namecheap и т.д.)
2. Найдите управление DNS записями
3. Добавьте CNAME запись:
   - **Тип**: CNAME
   - **Имя**: www (или @ для корневого домена)
   - **Значение**: consulting-website.onrender.com
4. Сохраните изменения
5. Дождитесь распространения DNS (может занять до 24 часов)

#### Шаг 4.3: Проверка домена
1. Вернитесь в Render Dashboard
2. Проверьте статус домена
3. Когда статус изменится на "Active", домен готов к использованию

## 🆘 Решение проблем

### Проблема: Сайт не загружается
**Решение:**
1. Проверьте логи в Render Dashboard
2. Убедитесь, что package.json содержит скрипт `start`
3. Проверьте, что все файлы загружены на GitHub
4. Перезагрузите сервис (нажмите "Restart")

### Проблема: Изображения не загружаются
**Решение:**
1. Проверьте пути к изображениям (должны быть относительные)
2. Убедитесь, что файлы изображений загружены на GitHub
3. Проверьте консоль браузера на ошибки 404
4. Очистите кэш браузера

### Проблема: Медленная загрузка
**Решение:**
1. Оптимизируйте размеры изображений
2. Используйте Render's CDN
3. Включите кэширование браузера
4. Минифицируйте CSS и JavaScript

### Проблема: Форма контактов не работает
**Решение:**
1. Проверьте консоль браузера на ошибки
2. Убедитесь, что JavaScript загружается корректно
3. Проверьте, что форма имеет правильные атрибуты
4. Настройте backend для обработки формы (Formspree, EmailJS и т.д.)

## 💡 Советы по оптимизации

1. **Оптимизация изображений**
