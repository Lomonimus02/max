## 🚀 Как развернуть на Render (Краткая инструкция)

### Шаг 1: Создание аккаунта (2 минуты)
1. Перейдите на https://render.com
2. Нажмите "Sign Up"
3. Выберите GitHub для регистрации
4. Авторизуйтесь

### Шаг 2: Подключение репозитория (3 минуты)
1. В Render Dashboard: New → Web Service
2. Выберите "Connect a repository"
3. Найдите `Lomonimus02/max`
4. Выберите ветку `consulting-website-render`

### Шаг 3: Конфигурация (2 минуты)
| Параметр | Значение |
|----------|----------|
| Name | consulting-website |
| Environment | Node |
| Build Command | npm run build |
| Start Command | npm start |
| Instance Type | Free |

### Шаг 4: Развертывание (5 минут)
1. Нажмите "Create Web Service"
2. Дождитесь завершения
3. Получите URL: `https://consulting-website.onrender.com`

**Общее время: ~12 минут**
