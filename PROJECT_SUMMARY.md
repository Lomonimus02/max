## 🚀 Как развернуть на Render

### Быстрый старт (5 минут)

1. **Создайте аккаунт на Render**
   - Перейдите на https://render.com
   - Зарегистрируйтесь через GitHub

2. **Подключите репозиторий**
   - В Render Dashboard: New → Web Service
   - Выберите репозиторий: `Lomonimus02/max`
   - Выберите ветку: `consulting-website-render`

3. **Настройте сервис**
   - Name: `consulting-website`
   - Environment: `Node`
   - Build Command: `npm run build`
   - Start Command: `npm start`

4. **Развертните**
   - Нажмите "Create Web Service"
   - Дождитесь завершения (2-5 минут)
   - Получите URL: `https://consulting-website.onrender.com`

### Подробные инструкции
Смотрите файл `DEPLOYMENT_INSTRUCTIONS.md` для полного пошагового руководства.
