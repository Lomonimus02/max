# Quick Start Guide

Быстрый старт для просмотра сайта с placeholder изображениями.

## 🚀 Запуск за 5 минут

### Шаг 1: Использование placeholder изображений

Если у вас пока нет готовых изображений, можно использовать временные placeholder'ы для тестирования.

#### Обновите index.html

Замените пути к изображениям на placeholder URL:

```html
<!-- Hero Section Background -->
<!-- В CSS файле css/style.css, строка ~130 -->
background-image: url('https://images.unsplash.com/photo-1514933651103-005eec06c04b?w=1920&h=1080&fit=crop');

<!-- Portfolio Images -->
<!-- Dubai Opera -->
<img src="https://images.unsplash.com/photo-1540039155733-5bb30b53aa14?w=800&h=600&fit=crop" alt="Dubai Opera Project">

<!-- Belcanto -->
<img src="https://images.unsplash.com/photo-1517248135467-4c7edcad34c4?w=800&h=600&fit=crop" alt="Belcanto Project">

<!-- More Than Home -->
<img src="https://images.unsplash.com/photo-1470337458703-46ad1756a187?w=800&h=600&fit=crop" alt="More Than Home Project">
```

### Шаг 2: Запуск локального сервера

#### Вариант A: Python (если установлен)

```bash
# Python 3
cd "Consulting Website"
python -m http.server 8000
```

Откройте браузер: http://localhost:8000

#### Вариант B: Node.js (если установлен)

```bash
# Установите http-server глобально (один раз)
npm install -g http-server

# Запустите сервер
cd "Consulting Website"
http-server
```

Откройте браузер: http://localhost:8080

#### Вариант C: VS Code Live Server

1. Установите расширение "Live Server" в VS Code
2. Откройте `index.html`
3. Нажмите "Go Live" в статус-баре

#### Вариант D: Просто откройте файл

Можно просто открыть `index.html` в браузере, но некоторые функции могут не работать из-за CORS политики.

## 📝 Быстрая кастомизация

### 1. Изменить цвета

Откройте `css/style.css` и измените переменные (строки 10-20):

```css
:root {
    --color-accent: #00d4ff;  /* Измените на ваш цвет */
}
```

Популярные варианты:
- Неоновый синий: `#00d4ff` (текущий)
- Неоновый оранжевый: `#ff6b35`
- Неоновый зеленый: `#00ff88`
- Неоновый фиолетовый: `#b24bf3`
- Золотой: `#ffd700`

### 2. Изменить заголовок

Откройте `index.html`, найдите строку ~50:

```html
<h1 class="hero-title">Ваш новый заголовок</h1>
```

### 3. Обновить контакты

Найдите секцию Contact (строка ~200):

```html
<a href="tel:+971501234567">Ваш номер</a>
<a href="mailto:info@yourdomain.com">Ваш email</a>
```

### 4. Изменить услуги

Найдите секцию Services (строка ~60):

```html
<li>Ваша услуга 1</li>
<li>Ваша услуга 2</li>
<!-- и т.д. -->
```

## 🔧 Быстрые исправления

### Проблема: Шрифты не загружаются

**Решение**: Проверьте интернет-соединение. Шрифты загружаются с Google Fonts.

Альтернатива - использовать системные шрифты:

```css
/* В css/style.css */
--font-primary: -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
--font-display: Georgia, serif;
```

### Проблема: Навигация не работает на мобильных

**Решение**: Убедитесь, что файл `js/main.js` загружается. Проверьте консоль браузера (F12).

### Проблема: Форма не отправляется

**Решение**: Это нормально! Форма требует настройки backend. См. `DEPLOYMENT.md` для инструкций.

Временно форма показывает уведомление об успехе без реальной отправки.

### Проблема: Изображения не отображаются

**Решение**: 
1. Проверьте пути к файлам
2. Убедитесь, что изображения находятся в правильных папках
3. Используйте placeholder URL (см. выше)

## 📱 Тестирование на мобильных

### В браузере (Chrome DevTools)

1. Откройте сайт в Chrome
2. Нажмите F12
3. Нажмите иконку мобильного устройства (Ctrl+Shift+M)
4. Выберите устройство из списка

### На реальном устройстве

1. Запустите локальный сервер
2. Узнайте IP адрес компьютера:
   ```bash
   # Windows
   ipconfig
   
   # Mac/Linux
   ifconfig
   ```
3. На мобильном устройстве откройте: `http://YOUR_IP:8000`
