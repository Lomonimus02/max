## 🎯 Как развернуть на Render за 5 минут

### Шаг 1: Создайте аккаунт на Render
1. Перейдите на https://render.com
2. Нажмите "Sign Up"
3. Выберите GitHub для регистрации

### Шаг 2: Подключите репозиторий
1. В Render Dashboard: New → Web Service
2. Выберите "Connect a repository"
3. Найдите `Lomonimus02/max`
4. Выберите ветку `consulting-website-render`

### Шаг 3: Настройте сервис
| Параметр | Значение |
|----------|----------|
| Name | consulting-website |
| Environment | Node |
| Build Command | npm run build |
| Start Command | npm start |

### Шаг 4: Развертните
1. Нажмите "Create Web Service"
2. Дождитесь завершения (2-5 минут)
3. Получите URL: `https://consulting-website.onrender.com`

## 🆘 Решение проблем

### Сайт не загружается
1. Проверьте логи в Render Dashboard
2. Убедитесь, что package.json содержит скрипт `start`
3. Проверьте, что все файлы загружены на GitHub

### Изображения не загружаются
1. Проверьте пути к изображениям (должны быть относительные)
2. Убедитесь, что файлы изображений загружены на GitHub
3. Проверьте консоль браузера на ошибки 404

### Медленная загрузка
1. Оптимизируйте размеры изображений
2. Используйте Render's CDN
3. Включите кэширование браузера
