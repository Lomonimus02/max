# Проект: Одностраничный веб-сайт для консалтинговой компании

## Общая информация
- **Название проекта**: Single-Page Website for Bar & Event Consulting Company
- **Цель**: Создание современного, лаконичного и профессионального онлайн-присутствия для привлечения потенциальных клиентов в Дубае
- **Целевая аудитория**: Владельцы и менеджеры ресторанов, баров, ночных клубов, event-агентств и организаторов мероприятий
- **Основное сообщение**: "Мы - эксперты полного цикла в создании и управлении прибыльными барными и event-проектами"

## Техническая архитектура
- **Тип**: Одностраничное приложение (SPA)
- **Структура**: 6 основных блоков с вертикальной прокруткой
- **Дизайн**: Темная тема, минимализм, адаптивный дизайн

## Визуальный стиль
- **Цветовая палитра**: 
  - Основной фон: темно-серый/черный
  - Текст: белый/светло-серый
  - Акцентный цвет: яркий современный (неоновый синий/оранжевый/белый)
- **Типографика**: Крупные, читаемые, современные sans-serif шрифты
- **Композиция**: Минимализм, много "воздуха", фокус на контенте

## Структура сайта

### Блок 1: Hero Section
- Фоновое видео/изображение высокого качества
- Логотип в верхнем левом углу
- Главный заголовок (H1)
- Подзаголовок с кратким объяснением
- CTA кнопка

### Блок 2: Services
- Два основных направления бизнеса
- Колоночная структура или переключаемые табы
- Иконки и описания услуг

### Блок 3: Portfolio
- Сетка из 3-4 значимых проектов
- Карточки с изображениями, логотипами клиентов и описаниями

### Блок 4: Our Clients
- Сетка логотипов клиентов
- Единообразный стиль логотипов

### Блок 5: Contact Us
- Контактная информация
- Форма обратной связи (опционально)

### Блок 6: Footer
- Логотип компании
- Copyright
- Дублированные контакты

## Технические требования
- Адаптивный дизайн (Mobile-First)
- Кроссбраузерная совместимость
- Оптимизация скорости загрузки
- Базовое SEO

## Реализованные компоненты

### 1. HTML Структура (index.html)
Создан полноценный одностраничный сайт с 6 основными блоками:

#### Навигация
- Фиксированная навигационная панель с логотипом
- Адаптивное меню с гамбургер-иконкой для мобильных устройств
- Плавная прокрутка к секциям
- Полупрозрачный фон с эффектом размытия (backdrop-filter)

#### Блок 1: Hero Section
- Полноэкранная секция с фоновым изображением
- Градиентный заголовок с эффектом gradient text
- Подзаголовок с описанием услуг
- CTA кнопка с плавной прокруткой к секции Services
- Темный оверлей для читаемости текста

#### Блок 2: Services
- Двухколоночная сетка услуг
- Карточки с иконками (SVG)
- Два направления бизнеса:
  1. Bar Management & Beverage Program Development
  2. Event & Entertainment Services
- Списки ключевых услуг (по 6 пунктов в каждом)

#### Блок 3: Portfolio
- Адаптивная сетка проектов (3 карточки)
- Каждая карточка содержит:
  - Изображение проекта
  - Логотип клиента
  - Название проекта
  - Краткое описание
- Hover эффекты с увеличением изображения
- Data-атрибуты для будущего функционала модальных окон

#### Блок 4: Our Clients
- Сетка логотипов клиентов (4 логотипа)
- Единообразный стиль (белые логотипы на темном фоне)
- Hover эффекты с подсветкой
- Анимация появления при прокрутке

#### Блок 5: Contact Us
- Двухколоночная структура:
  1. Контактная информация (телефон, email, WhatsApp, соцсети)
  2. Форма обратной связи
- Форма с полями:
  - Имя (обязательное)
  - Email (обязательное)
  - Телефон (опциональное)
  - Сообщение (обязательное)
- Кнопка отправки с валидацией

#### Блок 6: Footer
- Логотип компании
- Copyright информация
- Дублированные контакты
- Адаптивная структура

### 2. CSS Стили (css/style.css)

#### CSS Variables (Custom Properties)
Определены переменные для:
- Цветовой палитры (темная тема)
- Типографики (шрифты Inter и Playfair Display)
- Отступов (spacing system)
- Переходов (transitions)

#### Основные стили
- CSS Reset для кроссбраузерности
- Темная цветовая схема:
  - Фон: #0a0a0a (черный)
  - Вторичный фон: #1a1a1a (темно-серый)
  - Текст: #ffffff (белый)
  - Акцент: #00d4ff (неоновый синий)
- Плавные переходы и анимации
- Градиентные эффекты для заголовков

#### Компонентные стили
- **Навигация**: Фиксированная, полупрозрачная, с анимацией подчеркивания
- **Hero**: Полноэкранная секция с параллакс эффектом
- **Карточки**: Hover эффекты с трансформацией и тенями
- **Кнопки**: Градиентные тени, hover эффекты
- **Формы**: Стилизованные поля ввода с focus состояниями

### 3. Адаптивные стили (css/responsive.css)

#### Breakpoints
- Desktop: 1440px+
- Laptop: 1024px - 1439px
- Tablet: 768px - 1023px
- Mobile: 480px - 767px
- Small Mobile: <480px

#### Mobile-First подход
- Адаптивная навигация с гамбургер-меню
- Изменение сеток на одноколоночные
- Уменьшение размеров шрифтов
- Оптимизация отступов
- Landscape ориентация
- Print стили
- Reduced motion для accessibility

### 4. JavaScript функционал (js/main.js)

#### Реализованные функции
1. **Мобильная навигация**
   - Открытие/закрытие меню
   - Блокировка прокрутки при открытом меню
   - Закрытие при клике на ссылку

2. **Плавная прокрутка**
   - Smooth scroll к якорным ссылкам
   - Учет высоты навигации

3. **Динамический фон навигации**
   - Изменение прозрачности при прокрутке
   - Добавление тени

4. **Обработка формы**
   - Валидация полей
   - Email валидация через regex
   - Система уведомлений
   - Очистка формы после отправки

5. **Активная навигация**
   - Подсветка текущей секции в меню
   - Отслеживание позиции прокрутки

6. **Lazy loading изображений**
   - Intersection Observer API
   - Отложенная загрузка изображений

### 5. Анимации (js/animations.js)

#### Реализованные эффекты
1. **Scroll Reveal**
   - Fade-in анимация при прокрутке
   - Intersection Observer для производительности

2. **Parallax эффект**
   - Движение фона hero секции

3. **Hover эффекты**
   - 3D tilt для карточек портфолио
   - Glow эффект для карточек услуг
   - Ripple эффект для кнопок

4. **Floating анимация**
   - Плавающие логотипы клиентов

5. **Page load анимация**
   - Fade-in всей страницы

#### CSS Animations
- Keyframe анимации
- Transform эффекты
- Opacity transitions
- Cubic-bezier timing functions

## Технические особенности

### SEO оптимизация
- Семантический HTML5
- Meta теги (title, description)
- Один H1 заголовок
- Alt атрибуты для изображений
- Структурированная иерархия заголовков

### Производительность
- Минимальные зависимости (только Google Fonts)
- Оптимизированный CSS
- Эффективный JavaScript
- Lazy loading изображений
- CSS переменные для быстрых изменений

### Accessibility
- Семантические HTML элементы
- ARIA атрибуты где необходимо
- Keyboard navigation
- Focus states
- Reduced motion support
- Контрастные цвета

### Кроссбраузерность
- Современные CSS свойства с fallback
- Проверка поддержки JavaScript API
- Vendor prefixes где необходимо
- Тестирование в Chrome, Firefox, Safari, Edge
